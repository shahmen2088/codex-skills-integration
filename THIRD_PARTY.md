# Third-party material

This repository contains original integration scripts. It stages files from the nine adjacent, locally audited repositories at the commits declared in `config/source-lock.json`; their own MIT licenses remain in their source repositories. No third-party skill text or code is copied into this integration repository.

The staging output is intentionally not committed. It may contain the source skills and their referenced files only when the operator runs the staging command against the locked local sources.
